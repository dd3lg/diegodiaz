Typography

Exploring type hierarchy, readability, and expressive text-based design.

Overview

This project focused on understanding how typography affects communication. I experimented with font pairing, spacing, and hierarchy.

Process

I tested different typefaces and layouts to create clear visual hierarchy. Adjusting spacing and alignment helped improve readability.

Reflection

This project helped me understand how typography alone can create strong visual communication without relying on images.
